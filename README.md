

# UniverCity

A full-stack web application developed as a **Final Year Project at FAST University**, designed to help **high school graduates** make informed decisions when choosing from **160+ universities** across the country.

---

##  Overview

Choosing the right university is a critical step for students. This platform provides a **comprehensive, user-friendly solution** to explore, compare, and prepare for university admissions with smart features and automation.

---

##  Key Features

###  University Discovery
- Search and filter universities based on programs, location, admission criteria, and more.
- Compare universities side-by-side to make informed decisions.
- Explore detailed profiles including rankings, facilities, admission deadlines, and fee structures.

### 📝 Mock Test Preparation
- Attempt mock entry tests to prepare effectively.
- **AI-powered proctoring** using Microsoft's **Face API** ensures academic integrity and real-time monitoring.

### 📅 Custom Timetable
- Personalized schedule including:
  - Entry test dates
  - Application start/end dates
  - Interview schedules (if applicable)

### 🔔 Smart Notifications
- **WhatsApp & Gmail integration** to receive automatic reminders for important admission events such as:
  - Upcoming entry tests
  - Application deadline alerts

## 🛠️ Tech Stack

| Layer         | Technology        |
|---------------|-------------------|
| **Frontend**  | Angular 18         |
| **Backend**   | Spring Boot        |
| **Database**  | PostgreSQL         |
| **Cache**     | Redis              |
| **Face Recognition** |  Face API |
| **Swagger/OpenAPI** | API Documentation | 
| **Version Control** | Github |


---

## ☁️ Deployment

| Component         | Platform         |
|-------------------|------------------|
| **Frontend**      | [Vercel](https://vercel.com) |
| **Database**      | [Railway](https://railway.app) |
| **Backend API**   | [AWS EC2](https://aws.amazon.com/ec2) with HTTPS and SSL Certificates |

- Backend configured to accept only **secure (HTTPS)** inbound traffic.
- SSL certificates managed and signed for production-grade security.
- API seamlessly integrated with Vercel frontend and external services (Face API, Twilio, Gmail SMTP).

---

## 🛡️ Security & Scalability

- HTTPS with SSL certificates for secure communication.
- Redis caching for optimal performance and session handling.
- Modular architecture for easy scaling and deployment. 
- JWT Based Authentication using spring security.
